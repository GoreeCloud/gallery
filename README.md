# GoreeCloud Gallery

GoreeCloud Gallery is an Android photo and video gallery project centered on local-first, offline-first media management, privacy, and on-device capabilities.

## Documentation

- [Features and Capabilities Catalog](docs/FEATURES_AND_CAPABILITIES.md) — complete 18-section proposed product scope, including browsing, organization, editing, metadata, private vault, and offline requirements.
- [Editable DOCX catalog in GoreeCloud Drive](https://docs.google.com/document/d/1wXQzRwkEj4T_16sa-jlNXGVAfo5ww1C7/edit) — retained feature-roadmap document.

> **Status:** The catalog is a proposal and does not establish implementation, testing, release readiness, or Stable status. Verify those facts against current implementation and acceptance evidence.
